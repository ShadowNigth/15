CURRENT DELIVERY: EDITABLE GODOT SOURCE PROJECT
Extract the source ZIP into a new directory. Open Godot 4.3+, import
project.godot, wait for the resource import, and press F5.
This source ZIP does not include the engine, an executable, or a .pck export.
Previously published executable releases predate the current animation work.
An OpenGL 3.3-compatible graphics driver is required for GL Compatibility.

NATIVE FIREARM AND UTILITY ANIMATIONS
42 model-specific source sets: 35 guns, six grenades and C4; 289 native clips
and 52 available inspections. Original geometry, skins, arms, gloves, weights
and inverse binds are preserved. Action animation and sound playback is fitted
to existing gameplay timers; weapon statistics and map/bot rules are unchanged.
R8 additive preparation, CZ75 spare-magazine state, suppressor transitions and
per-shell shotgun reload stages are handled explicitly. Auxiliary source graph
clips remain available without replacing classic gameplay with CS2 mechanics.
See NATIVE_WEAPON_ANIMATIONS.md for provenance and reproducible tests.

NATIVE AUDIO
649 original WAV/OGG recordings from the pinned source repository, with per-file
hashes. Weapon/knife effects, synchronized mechanical cues, grenades, fire,
smoke, C4, impacts and casings replace matching legacy routes. English/Chinese
CT/T radio voices are selectable in Configuration -> Radio voices. The Arsenal
includes an all-recordings selector with Listen/Stop, including assets for
unimplemented chicken/shield/deathmatch mechanics without inventing those modes.
See docs/NATIVE_AUDIO.md for routing, fallbacks, attribution and tests.

KNIVES AND FINISHES
Create Game -> Knife model: original Kukri + all 22 source knife models.
The 3D Arsenal also lists the knives; selecting one sets the loadout.
Arsenal -> Weapon finish: choose a matching finish for the selected model.
The catalog includes 22 factory and 20 painted knife finishes, 44 gun finishes
from ScCsgoKnives, plus the 120 previously installed BDS/CS:GO Ports finishes.
New gun entries are labelled '(CS2 catalog)' to distinguish alternate bakes of
the same paint kit without replacing previously accepted artwork.
3: equip knife. Left click: light slash. Right click: heavy stab. T: inspect.
Knife chrome is subordinate to base-colour artwork; normal/ORM follow the finish.
Current source project: 22 model-specific native animation sets (235 clips,
33 inspection variants), retargeted to the original arm/glove geometry.
Classic gameplay balance is retained. Earlier executable releases predate this
animation correction; see VERSION.txt and the release notes for their scope.
Sport Glove selection continues to work. Each knife remembers its own finish.

WASD move; mouse aim; Space jump; Ctrl crouch; Shift walk; B buy;
1/2/3/4/5 weapon slots; R reload; E use/rescue/defuse; Tab scores; Esc pause.
26 classic maps, local bots, hostages, VIP and bomb missions; no networking.
