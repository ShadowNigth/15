COUNTER-STRIKE 1.5 — GODOT FAN REMAKE
COMPLETE SHIPPED COSMETIC CATALOG

Windows: extract the entire ZIP and run CounterStrike15.exe.
Linux: extract the entire ZIP, enable executable permission if necessary
(chmod +x CounterStrike15.x86_64), then run CounterStrike15.x86_64.
Keep the .pck file next to the executable. Godot installation is not required.
64-bit PC and an OpenGL 3.3-compatible graphics driver are required.

KNIVES AND FINISHES
Create Game -> Knife model: original Kukri + all 22 source knife models.
The 3D Arsenal also lists the knives; selecting one sets the loadout.
Arsenal -> Weapon finish: choose a matching finish for the selected model.
The catalog includes 22 factory and 20 painted knife finishes, 44 gun finishes
from ScCsgoKnives, plus the 120 previously installed BDS/CS:GO Ports finishes.
New gun entries are labelled '(CS2 catalog)' to distinguish alternate bakes of
the same paint kit without replacing previously accepted artwork.
3: equip knife. Left click: light slash. Right click: heavy stab. T: inspect.
Knife chrome is subordinate to base-colour artwork; normal/ORM follow the finish.
Current source project: 22 model-specific native animation sets (235 clips,
33 inspection variants), retargeted to the original arm/glove geometry.
Classic gameplay balance is retained. Earlier executable releases predate this
animation correction; see VERSION.txt and the release notes for their scope.
Sport Glove selection continues to work. Each knife remembers its own finish.

WASD move; mouse aim; Space jump; Ctrl crouch; Shift walk; B buy;
1/2/3/4/5 weapon slots; R reload; E use/rescue/defuse; Tab scores; Esc pause.
26 classic maps, local bots, hostages, VIP and bomb missions; no networking.

This is an unofficial fan project. Third-party assets are not covered by a
blanket free-use license. Read KNIFE_ASSET_NOTICES.md and PROJECT_README.md.
The catalog covers the source repository's shipped assets, not every Valve skin.
